OE5XRX Audio Self-Test

Open in a WebCodecs-capable browser (Chrome 94+, Edge 94+, Firefox 130+).
This page is a standalone dev tool — no server required.
It decodes the embedded 291-byte fixture (media_frame_slot0rx.bin),
renders it into an OfflineAudioContext, runs an FFT, and asserts the
dominant frequency bin is approximately 1000 Hz.
