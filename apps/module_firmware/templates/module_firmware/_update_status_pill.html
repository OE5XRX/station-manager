{% comment %} Firmware update status of one module (update_status.UpdateStatus). Expects `module` and `status`. Optional flags: - `compact`: short label, full reason as tooltip (module list, station card). Without it (module detail) the full reason line sits next to the pill. - `nopoll`: never poll (module list: a reload is enough). - `card`: station card. Always polls: every 5 s while live, otherwise every 30 s, plus right away on the `fw-status-refresh` body event that control-panel.js fires when a module leaves the live flash state. A card on an open control panel must never freeze on a pre-flash or settled state. Outside the card, the root element re-fetches itself every 5 s only while the state can still change on its own (status.is_live); a settled state renders without hx-* attributes, so the polling stops by itself. {% endcomment %} {% with s=status.state %} {% if s != 'no_target' %}{% endif %}{% if compact and s == 'running' %}{{ status.reason_text }}{% else %}{{ status.short_label }}{% endif %} {% if not compact and status.reason_text != status.short_label %}{{ status.reason_text }}{% endif %} {% endwith %}
