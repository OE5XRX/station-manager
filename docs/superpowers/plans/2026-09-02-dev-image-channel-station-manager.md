# Dev-Image Channel — station-manager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Der station-manager erkennt, importiert, deployt und zeigt dev- vs. release-Images an, getrieben von einem dynamischen `channel`-String, der aus dem Asset-Namen gelesen und via Heartbeat als laufende Variante gemeldet wird.

**Architecture:** Neuer `channel`-CharField auf `ImageRelease`/`ImageImportJob` (freier Slug, Default `release`), channel-getrennte Constraints/Storage-Keys. Der Release-Browser liest den Channel dynamisch aus symmetrisch benannten Assets (`oe5xrx-<machine>-<channel>-<tag>.wic.bz2`). Der Agent meldet den gebackenen `VARIANT_ID` als `image_variant`; der Server speichert ihn in `Station.current_image_variant` und zeigt ein Badge überall wo ein Image/Release erscheint. cosign-Verifikation und rootfs-Extraktion bleiben unverändert (variant-agnostisch).

**Tech Stack:** Django 6.0, DRF 3.17, PostgreSQL, HTMX, Bootstrap-Pills (`static/css/app.css`), pytest/Django TestCase.

**Spec:** `docs/superpowers/specs/2026-09-02-dev-image-channel-design.md`

## Global Constraints

- Asset-Naming symmetrisch: `oe5xrx-<machine>-<channel>-<tag>.wic.bz2` (+`.sha256`, +`.bundle`). Kein Legacy-Fallback auf `oe5xrx-<machine>-<tag>.wic.bz2`.
- `channel` ist ein freier lowercase-Slug (`[a-z0-9-]+`), **keine** harten DB-`choices`. Default `release`.
- Channel-Extraktion aus Asset-Namen **nie** per naivem `-`-Split (machine enthält `-`): bekannten Prefix `oe5xrx-<machine>-` und Suffix `-<tag>.wic.bz2` abziehen.
- cosign (`apps/images/cosign.py`) und rootfs-Extraktion (`apps/images/extraction.py`) bleiben **unverändert**.
- Bestehende `ImageRelease`-Rows bekommen `channel="release"` über den Column-Default.
- Django-Template-Kommentare: kein multiline `{# … #}`, immer `{% comment %}`.
- Migrationen: Konvention `# Generated by Django 6.0.x`, ein Feld/Constraint pro Operation-Block.
- Neueste stabile Lib-Versionen; keine alten Defaults.

```python
    def has_assets_for(self, machine: str, channel: str) -> bool:
        base = f"oe5xrx-{machine}-{channel}-{self.tag}.wic.bz2"
        return all(
            name in self.asset_names for name in (base, f"{base}.bundle", f"{base}.sha256")
        )

    def channels_for(self, machine: str) -> frozenset[str]:
        """Channels with a complete (wic+sha256+bundle) asset triple.

        Extract the channel token by stripping the known prefix and
        suffix — NEVER split on '-', because ``machine`` itself contains
        hyphens (qemux86-64, raspberrypi4-64).
        """
        prefix = f"oe5xrx-{machine}-"
        suffix = f"-{self.tag}.wic.bz2"
        channels = set()
        for name in self.asset_names:
            if name.startswith(prefix) and name.endswith(suffix):
                channel = name[len(prefix) : -len(suffix)]
                if channel and self.has_assets_for(machine, channel):
                    channels.add(channel)
        return frozenset(channels)
```

_OS_RELEASE_PATH = "/etc/os-release"


def get_image_variant() -> str:
    """Read the baked image channel (VARIANT_ID) from /etc/os-release."""
    try:
        with open(_OS_RELEASE_PATH) as f:
            for line in f:
                if line.startswith("VARIANT_ID="):
                    return line.split("=", 1)[1].strip().strip('"')
    except OSError:
        logger.debug("Could not read /etc/os-release for VARIANT_ID")
    return ""
