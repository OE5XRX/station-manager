# SSTV Receive & Transmit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lock holders receive SSTV pictures (live line-by-line, saved to a per-station gallery) and transmit uploaded or generated pictures with callsign overlays, decoded and keyed on the station.

**Architecture:** One shared Python package `station_agent/sstv/` holds the mode table, a pure-Python encoder (used by the server) and a numpy decoder (used on the station inside the sandboxed `oe5xrx-decoder@sstv-slotN` unit). The agent's `DecoderHost` gets an `sstv` plugin (live rows unreliable, final PNG reliable) and a new station-side TX session (download → key → play → unkey, hard-stopped). The server adds `apps/sstv` (models, rendering, gallery, guards, lock-hook integration) and a collapsible SSTV section on the control page.

**Tech Stack:** Django 6 / Channels, Pillow (server, already pinned), numpy (station decoder + dev/test only, never imported by server code), GStreamer `gst-launch-1.0` + PipeWire on the station, Alpine.js, Yocto (linux-image).

**Spec:** `docs/superpowers/specs/2026-11-24-sstv-design.md` (read it first; this plan argues from it). APRS framework spec: `docs/superpowers/specs/2026-11-10-passive-services-aprs-design.md`.

## Global Constraints

- Modes, RX and TX: Martin M1, M2; Scottie S1, S2, DX; Robot 36, 72; PD 90, 120, 180. Nothing else.
- Only the ControlLock holder with `sstv.use` starts RX/TX. Permission area `sstv`: view = Applicant, use = Member, manage = Staff.
- RX `max_runtime_s` = 1800. Pictures with < 10 % of rows received are discarded.
- TX hard stop in the agent at `duration_s + 5` s; also on `sstv_tx_stop`, control-WS loss, playback failure, lock loss. TX refused if TX frequency within 145.800 MHz ± 10 kHz or outside the module's TX `ranges`.
- TX audio: 8000 Hz, mono, s16le, generated by the server; playback scaled to the station's TX ceiling (`TxAudioSettings.ceiling_dbfs`), never through the voice DSP chain.
- Holder's browser gone → existing `RECONNECT_GRACE_SECONDS` release → RX ends (partial saved), TX aborted. Agent link lost → agent stops SSTV RX itself and spools the partial picture; aborts TX.
- Running SSTV RX/TX counts as lock activity for the idle sweep.
- Retention: `SstvSettings.retention_days` default 90 (admin-editable), enforced by `enforce_retention` honouring `RETENTION_ENFORCE`. Untransmitted uploads/previews never kept beyond 1 h.
- i18n: English msgids, German translation (Du-Form) in `locale/de/.../django.po` / `djangojs.po` in the same PR; `scripts/i18n.sh check` green. German labels in the spec are the intended translations.
- Templates: `{% comment %}` only, no multi-line `{# #}`. No inline JS; Alpine components register via `Alpine.data` on `alpine:init`. Number inputs `lang="en"`. UI work: invoke `Skill("frontend-design")`.
- Tests top-level `tests/test_*.py`; `python -m pytest -q`; `uvx ruff@0.16.8 check . && uvx ruff@0.16.8 format --check .`.
- numpy: add the newest stable release (check PyPI) to `requirements/dev.in` only; server modules never import `station_agent.sstv.decoder`.
- Note vs spec: the longest mode is **Scottie DX (~269 s)**, not PD180; TX artefact size limit therefore 5 MB (269 s × 16 KB/s ≈ 4.3 MB).

## Review Focus

1. **Odd uploads** — EXIF-rotated phone JPEG, PNG with alpha, CMYK JPEG, 1×4000 px panorama, a decompression bomb: preview is upright, opaque, filled to the mode aspect, bomb rejected with a message. → Task 8.
2. **Frequency changed after preview** (e.g. user presses ISS after previewing): the send guard is evaluated at send time against the module's current `last_state`, not at preview time. → Task 10.
3. **Double send** (two tabs of the same holder, or double click): exactly one TX session; the second gets `sstv_busy`. → Tasks 6 and 10.
4. **Agent reconnect during TX**: a reconnecting agent never re-keys; the server marks the transmission `aborted` on agent disconnect and never resends `sstv_tx_start`. → Tasks 6 and 10.
5. **30 min of pure noise / voice on RX**: no garbage pictures — VIS needs parity + both 1900 Hz leader halves; voice never yields `start`. → Task 3.
